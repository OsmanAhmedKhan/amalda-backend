# Security & Disclosure Policy

Security and data integrity are fundamental to the AMALDA architecture. We prioritize prompt mitigation of any vulnerabilities affecting document extraction, vector persistence, or LLM prompt injection.

## Supported Versions

| Version | Status | Security Updates |
| ------- | ------ | ---------------- |
| **1.0.x** | Active | :white_check_mark: |
| **< 1.0** | Deprecated | :x: |

## Reporting a Vulnerability

**CRITICAL: Do not report security vulnerabilities through public GitHub issues.**

If you discover a vulnerability within the AMALDA backend, please contact the repository owner directly via private professional channels (LinkedIn or direct email). 

Please include:
* A detailed technical description of the vulnerability.
* Steps to reproduce the exploit.
* Potential impact on the ASGI gateway or ChromaDB vector store.

Reports are reviewed strictly, and you will receive an acknowledgment within 48 hours.
